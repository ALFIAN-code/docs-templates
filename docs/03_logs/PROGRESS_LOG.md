# Progress Log

> Log kronologis tiap sesi kerja dengan AI agent. **Ini file yang paling penting dibaca AI di awal sesi** — isinya adalah "ingatan jangka pendek" project. Entry baru ditambahkan di paling atas (setelah judul), bukan menimpa entry lama.
>
> Dua baris identitas tiap entry diambil dari mesin, **jangan dari ingatan**:
> `## [YYYY-MM-DD HH:mm]` dari `date "+%Y-%m-%d %H:%M"`, dan `**Kontributor:**` dari `git config user.name`.
> Ambil keduanya dalam satu perintah bash. Laporan progress harian disusun dari gabungan file ini (konteks fitur)
> + `git log` (atribusi siapa mengerjakan).
